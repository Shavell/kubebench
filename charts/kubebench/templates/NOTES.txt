KubeBench {{ include "kubebench.version" . }} is installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

1. Open the UI:
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
     http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }} 8080:{{ .Values.service.port }}
     # then browse to http://localhost:8080
{{- end }}

2. Sign in as "admin".
{{- if $secretName }}
{{- if .Values.auth.existingSecret }}
   The password is in your Secret "{{ .Values.auth.existingSecret }}" (key "{{ .Values.auth.existingSecretKey }}").
{{- else }}
   Password:
     kubectl -n {{ .Release.Namespace }} get secret {{ $secretName }} -o jsonpath='{.data.admin-password}' | base64 -d; echo
{{- if .Values.auth.adminPassword }}
   It was set with auth.adminPassword, so it is also stored in the Helm release
   history; prefer auth.existingSecret for production.
{{- end }}
{{- end }}
   The password bootstraps the database on the first start only; KubeBench
   asks for a new one at the first sign-in.
{{- else }}
   The password is "admin" and must be changed at the first sign-in. Do that
   right away: until then anyone who can reach the UI can claim the account.
{{- end }}

   "{{ include "kubebench.serviceAccountName" . }}"
