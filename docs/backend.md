# Backend API

The HTTP API of the Go backend is documented in [`api.md`](api.md): every
route with its method, access level, parameters, answer and error codes.
The backend's packages, router and plugin platform are described in
[`architecture.md`](architecture.md), backend plugin development in
[`plugins.md`](plugins.md), and the behaviour behind each route in the
v0.5 contract [`design-v0.5.md`](design-v0.5.md) (§3–§7).
